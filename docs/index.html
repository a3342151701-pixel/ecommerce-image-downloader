01 产品介绍

图片散落在详情页，取图应该是件利落的事。

「电商图片提取」是一个 Chrome 扩展。它把当前商品详情页上的主图、轮播图与详情图收集到同一个页面，让你挑需要的，存成本地 PNG。

不登录卖家账号，不打开设计软件，也不逐张右键另存。

打开受支持的商品详情页，右下角会多出一个「获取图片」按钮。点击后，扩展读取页面上公开的图片地址，去掉重复项与缩略图后缀，在新标签页里集中展示。

勾选、预览、下载都在本机完成。它不读取账号、Cookie 或订单，也不把图片上传到任何服务器。

适用人群：电商运营、设计、内容与素材归档人员。

  1. 01

    上新与改版

    从自家或竞品详情页取回主图与详情图，整理成下一版上架素材。

  2. 02

    设计对接

    把选好的商品图交给设计或运营，不再让对方逐张保存、反复确认。

  3. 03

    素材归档

    按商品批量收图，统一为 PNG 存入下载目录的 ecom-images 文件夹。

02 核心功能

四个动作，一条完整的取图路径。

从详情页入口到本地文件，每一步都只为取图服务。点击下面的步骤，看看具体发生了什么。

详情页右下角，点一下「获取图片」

扩展只在受支持的商品详情页出现入口。点击后读取主图、轮播与描述中的图片地址，去掉重复项，并把常见的缩略图后缀还原为更大的版本。

  • 只在商品详情页注入按钮
  • 单页跳转后自动重新判断
  • 图标、logo 与过小的装饰图会被过滤

新页面集中预览，逐张勾选

提取结果在新标签页打开，缩略图平铺展示。默认全选，你可以取消不需要的，也可以点开图片放大确认，顶部会实时显示已选数量。

  • 支持全选与取消全选
  • 单击缩略图查看大图
  • 勾选数量随操作即时更新

只下载勾选项，统一转成 PNG

点击「下载所选」后，扩展先检查本地已有的 product 编号，再从数字最小的空号开始命名。图片在浏览器内用 Canvas 转为 PNG，逐张保存；某一张失败，不会影响其余图片。

  • 保存到下载目录的 ecom-images 文件夹
  • 已有 01、02、04 时，本批从 03 开始，遇到占用就跳过
  • 本地删除图片后，对应编号重新可用
  • 结束后显示成功与失败数量

三个平台，同一条取图路径

覆盖淘宝 / 天猫、京东、拼多多商家版的商品详情页。页面条件不满足时，按钮不会出现，也不影响浏览器正常使用。

  • 淘宝 / 天猫：商品详情地址包含商品 id

03 安装步骤

在 Chrome 里，加载这个文件夹。

当前版本通过 Chrome 开发者模式安装，不需要应用商店账号。按下面的顺序操作，完成后打开商品详情页即可使用。

  1. 01

    打开扩展管理页

    在 Chrome 地址栏输入 chrome://extensions 并回车，进入「扩展程序」页面。

  2. 02

    打开「开发者模式」

    在页面右上角把「开发者模式」开关打开。开启后，页面上才会出现加载本地扩展的操作按钮。

  3. 03

    点击「加载已解压的扩展程序」

    按钮位于扩展程序页面顶部。点击后，Chrome 会要求你选择一个本地文件夹。

  4. 04

    选择扩展目录

    选中 ecommerce-image-downloader 文件夹，也就是包含 manifest.json 的那一层，而不是它的上级目录。

  5. 05

    打开商品详情页使用

    刷新已经打开的商品页。右下角出现「获取图片」后，点击它，在新页面勾选图片，再点「下载所选」。

安装完成后，可以在 Chrome 工具栏的扩展菜单里固定图标。之后如果更新了扩展代码，回到 chrome://extensions，点击扩展卡片上的刷新按钮即可生效。

04 支持平台

三个平台，同一个入口。

按钮只会出现在符合条件的商品详情页。列表页、搜索页与店铺首页不会注入入口。

平台 生效页面 入口位置
  • 淘 淘宝 / 天猫

    商品详情页，地址中包含商品 id。支持淘宝与天猫两个域名。

    item.taobao.com/item.htm?id=… detail.tmall.com/item.htm?id=…

    右下角「获取图片」
  • 京 京东

    商品详情页，路径为数字 .html，或包含 /product/数字。

    item.jd.com/100012043978.html

    右下角「获取图片」
  • 拼 拼多多商家版

    仅商家后台 mms.pinduoduo.com 的商品相关页面：地址含 goods，且为详情、编辑、预览页，或带有 goods_id。

    不包含拼多多买家版商品页。

    右下角「获取图片」

其他页面不会出现按钮；在单页应用内跳转后，扩展会重新判断当前地址，离开详情页时按钮自动消失。

提取结果只包含当前详情页公开的图片地址。具体能取到哪些图，取决于页面结构与图床是否允许请求。

05 常见问题

安装前后，可能会问的几件事。

需要登录淘宝、京东或拼多多账号吗？

不需要。扩展不读取账号、Cookie 或订单，只读取当前详情页中公开显示的商品图地址。拼多多商家版本身需要你已登录后台才能打开商品页，但扩展不会接触登录信息。

下载的图片保存在哪里？

浏览器默认下载目录下的 ecom-images 文件夹，文件名形如 product-01.png，按编号递增。每批下载前，扩展会检查本地已有的编号，从数字最小的空号开始命名，遇到已占用编号就跳过；例如已有 01、02、04，本批会使用 03、05、06，不会覆盖已有文件。本地删除图片后，对应编号会重新可用；若刚删除就立刻开始下一批，Chrome 需要几秒刷新文件状态，该编号可能暂时仍被跳过，稍后再下载即可。如果 Chrome 设置为每次询问保存位置，会先弹出保存对话框。

为什么详情页右下角没有按钮？

先确认当前是受支持的商品详情页，而不是首页、搜索列表或店铺页。刚安装或更新扩展后，请刷新页面。仍然不出现时，在 chrome://extensions 确认扩展已启用，且没有报错。

图片会上传到服务器吗？

不会。扩展读取图片地址，在浏览器内用 Canvas 转换为 PNG，再交给 Chrome 的下载管理器。图片不经过第三方服务器，也不保存在扩展自己的空间里。

支持拼多多买家版吗？

暂不支持。当前只覆盖拼多多商家后台 mms.pinduoduo.com 的商品相关页面，买家版商品详情页不会出现入口。

下载时提示部分图片失败怎么办？

部分图床会拒绝扩展发起的图片请求。下载页会显示成功与失败数量，已经保存的图片不受影响。可以重试，或减少一次勾选的数量再试。

平台页面改版后取不到图？

商品页结构经常调整。如果主图既不在页面图片里，也不在页面脚本或描述页中，本次提取可能为空。可以刷新后重试；持续取不到时，需要等待扩展适配新的页面结构。
